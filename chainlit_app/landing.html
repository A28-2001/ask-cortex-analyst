A controlled evaluation of llm grounding

Ground an LLM in a real semantic model, and it stops guessing.

Ask Cortex Analyst is a natural-language interface to a Snowflake data warehouse, built to test that claim, not assume it. I ran the same 36 business questions, plus 8 adversarial ones, through two systems: one wired to a documented semantic layer via Snowflake Cortex Analyst, and one left to guess from raw table names alone. Same data, same questions, one variable changed.

Architecture

How it's built

The gap above isn't a smarter model. It's what stands between the model and the warehouse.

01

Snowflake + dbt

SaaS billing data modeled into clean, tested marts: MRR movements, cohorts, health scores, anomaly flags.

→
02

Semantic model

A YAML layer documenting business names, valid categorical values, verified queries, and explicit refusal rules, written once and reused for every question.

→
03

Cortex Analyst

Turns a question into SQL grounded in that documented context. The baseline gets raw table/column names: nothing else.

→
04

Chainlit app

Executes the generated SQL and renders the result. This app is deployed on Render.
